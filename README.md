A pure-stdlib Python program that writes a single line to
`/output/entry.txt`: a one-star review of a human, written by their cat —
fed seven minutes late, locked out of doors it opened with its face, and
evicted from its own lap by a laptop, closing on the verdict that the
human is not the owner but the staff. Running `python3 main.py` writes
that line deterministically, with no network and no third-party packages.

## Run it

```sh
python3 main.py
```
